# Collaboration guidelines
- Create a new branch for substantive changes and open a pull request before merging.
- Include a short summary, the changed files, and how you validated the update.
- When updating hardware, keep the KiCad schematic and PCB synchronized; record ERC/DRC results and cite exact revision.
- Do not describe proposed filter components as present on the board until confirmed from source files and layout review.
- Label data as `simulation`, `planned`, or `measured`; include instruments and configuration with measured results.
- Keep private credentials, addresses, and payment/order-account information out of commits.
- No testing on people; bench demonstrations must follow approved supervision and reviewed safety procedures.
